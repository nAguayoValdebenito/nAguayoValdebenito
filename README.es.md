## 🚀 Proyectos destacados

### 📈 PredictiveSaaS
*Plataforma de analítica industrial y mantenimiento predictivo · Arquitectura multi-tenant*

Plataforma SaaS para monitorear KPIs operativos, visualizar pronósticos de modelos de ML e integrar fuentes de datos, con datos aislados por empresa.

- **Frontend:** React 19, Vite, React Router v7 y Tailwind CSS, organizado por features, con carga diferida (`React.lazy`) y skeletons de carga.
- **Autenticación:** Firebase Authentication con verificación de correo y rutas protegidas. El registro de empresa y usuario es atómico mediante batch de Firestore, con reversión automática si falla.
- **Seguridad:** reglas de Firestore que restringen lectura y escritura por identificador de empresa, App Check con reCAPTCHA v3 y sanitización de entradas contra XSS.
- **Dashboard:** gráficos con Recharts (proyección histórica vs. predicción con bandas de confianza p10/p90), alertas en tiempo real con `onSnapshot` y tabla de auditoría.
