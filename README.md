## 🚀 Featured projects

### 📈 PredictiveSaaS
*Industrial analytics and predictive maintenance platform · Multi-tenant architecture*

SaaS platform to monitor operational KPIs, view ML forecasts and integrate data sources, with data isolated per company.

- **Frontend:** React 19, Vite, React Router v7 and Tailwind CSS, organized by features, with lazy loading (`React.lazy`) and loading skeletons.
- **Auth:** Firebase Authentication with email verification and protected routes. Company and user sign-up is atomic through a Firestore batch, with automatic rollback on failure.
- **Security:** Firestore rules restricting read/write by company ID, App Check with reCAPTCHA v3, and input sanitization against XSS.
- **Dashboard:** Recharts charts (historical vs. forecast with p10/p90 confidence bands), real-time alerts with `onSnapshot` and an audit table.
